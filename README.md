# decksell

Outil d'estimation de decks Magic : The Gathering (Modern) : prix total, fourchette de revente et matching avec les archétypes du méta. Étape suivante possible : annonces entre particuliers.

## Stack

Next.js (Vercel) · Supabase (Postgres) · GitHub

## Démarrage

1. `npm install`
2. Copier `.env.example` vers `.env.local` et renseigner les clés Supabase
3. `npm run dev`

## Mentions

Données de cartes et prix : Scryfall (prix EUR issus de Cardmarket), indicatifs et datés.
